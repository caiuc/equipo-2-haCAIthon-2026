# Probar SIRENA sin instalar nada

Este proyecto se puede levantar directamente en el navegador con GitHub Codespaces.

1. En la portada del repositorio, abre el botón verde **Code**.
2. Entra a la pestaña **Codespaces** y elige **Create codespace on main**.
3. Espera a que termine la preparación. La primera vez toma algunos minutos porque
   se instalan las dependencias.
4. Cuando la aplicación arranque, aparece un aviso para abrir el puerto 3000 en el
   navegador. Si no aparece, está en la pestaña **Ports** de la terminal.

El entorno queda aislado y se puede borrar al terminar. No modifica el repositorio.

## Qué queda fuera

El registro por voz y los paneles necesitan un proyecto Supabase propio en .env.
